# ⚡ Bioinformática & Automação Avançada

Este repositório contém ferramentas para a automação de pipelines de bioinformática, CI/CD e fluxos de escrita científica.

### 🚀 Destaques do Repositório:
* **Escrita Científica (LaTeX)**: Automação de compilação de papers usando `Makefile` para garantir reprodutibilidade.
* **Integração Contínua (GitHub Actions)**: Workflows configurados para revisão automática de texto e testes de scripts.
* **Gerenciamento de Build**: Uso de Makefiles para simplificar tarefas complexas de sistema.

---
*Foco: Automatizar o que é repetitivo para focar na descoberta biológica.*
